
# NovaTech Responsive Landing Page

## Live Demo
https://novatech-ivory.vercel.app/

## Project Description
NovaTech is a sample productivity platform landing page
developed as part of a Web Development Internship task.

The website demonstrates a responsive layout and a clean,
modern interface for a sample software product.

## Features
- Responsive header and navigation menu
- Hero section with call-to-action buttons
- Product dashboard preview
- Three feature cards
- About and contact sections
- Responsive footer
- Mobile navigation using JavaScript
- Responsive layouts using CSS Flexbox and Grid
- Accessibility improvements and reduced-motion support

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chrome DevTools

## Project Structure
- index.html: Page structure
- css/style.css: Styling and responsive layouts
- js/script.js: Navigation and button interactions
- README.md: Project documentation

## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Alternatively, use the Live Server extension in VS Code.

## Responsive Testing
Test the website at the following viewport widths:
- 320px: Small mobile
- 375px: Mobile
- 768px: Tablet
- 1024px: Laptop
- 1440px: Desktop

## Limitations
This is a front-end demonstration. Account creation,
data storage, and backend services are not implemented.
